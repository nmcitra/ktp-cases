# Security

## Reporting

Report a problem that should not be public (a case whose pass condition can be satisfied by an implementation that is unsafe, for example) privately through GitHub's security advisory form for this repository (Security → Report a vulnerability). Do not open a public issue for it. You will get an acknowledgement within seven days and a fix or a reasoned response within thirty.

## Scope

The case sets and published runs in this repository. Implementations that run them have their own security contacts.

## Practice

Secret scanning and push protection are on. Tags are never moved; a correction is a new tag that says so. Commits carry a DCO sign-off. Nothing here is a security claim about any implementation.
